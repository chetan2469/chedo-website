Chedo Tech Programming Institute Website
Requirements: PHP 8+, MySQL, Apache/Nginx
Setup:
1. Create database using database/schema.sql
2. Import database/seed.sql and database/seed_courses.sql
3. Copy config/database.example.php to config/database.php and fill credentials
4. Set uploads/ and admin/ permissions as needed
5. Change default admin password after first login
Deployment:
- Upload all files to web root
- Ensure .htaccess or server config allows PHP
- Configure contact/enquiry endpoints securely
